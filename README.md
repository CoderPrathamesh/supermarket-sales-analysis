# Supermarket Sales Analysis

Exploratory Data Analysis (EDA) of supermarket sales data using Python to understand sales trends, customer behavior, and product performance.

### Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn

### Key Analysis
- Analyzed sales and revenue patterns.
- Compared product line performance.
- Explored customer types and payment methods.
- Examined ratings and purchasing behavior.

### Project Structure
- `supermarket_sales.csv` — Dataset
- `supermarket_sales_analysis.ipynb` — Analysis notebook

### Run Locally
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook
```

Open the analysis notebook and run the cells.
